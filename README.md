# traceenv

Trace structured JSON env payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/traceenv/

## Install / run

```bash
git clone https://github.com/theworker02/traceenv.git
cd traceenv
node src/cli.js
node --test
```
